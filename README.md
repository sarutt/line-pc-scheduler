# LINE PC Auto-Sender (Windows + Python)

ส่งข้อความอัตโนมัติเข้า **กลุ่ม LINE** ตามเวลาที่ตั้งไว้ ด้วยการ automation แอป **LINE PC (เดสก์ท็อป)** บน Windows
ไม่ต้องมี Access Token, ไม่ต้องเป็นแอดมิน, ไม่ต้องเอาบอทเข้ากลุ่ม — สคริปต์จะ "จำลองการพิมพ์+คลิก" เหมือนเราส่งเอง

> โปรเจกต์นี้แยกอิสระ ไม่เกี่ยวกับ Project Trade

---

## ⚠️ อ่านก่อนใช้

- **ผิด LINE Terms of Service** — automation บัญชีมีความเสี่ยงถูกระงับบัญชี (ต่ำ แต่ไม่เป็นศูนย์) อย่าส่งถี่เกินไป
- เครื่องต้อง **เปิดค้าง + ล็อกอิน LINE + ต่อเน็ต** ตลอดเวลาที่จะส่ง
- ช่วงที่ส่ง สคริปต์จะ **ยึดเมาส์/คีย์บอร์ดชั่วขณะ** และดึงหน้าต่าง LINE ขึ้นมาหน้าสุด — อย่าเพิ่งใช้เครื่องตอนนั้น
- ถ้าเปลี่ยนธีม/ขนาดหน้าต่าง/ความละเอียดจอ ต้อง **calibrate พิกัดใหม่**

---

## ความต้องการของระบบ

- Windows 10/11
- **Python 3.9+** (ติ๊ก "Add Python to PATH" ตอนติดตั้ง)
- แอป **LINE PC** ติดตั้ง + ล็อกอิน + อยู่ในกลุ่มเป้าหมาย

## 🚀 วิธีเริ่มระบบ (ตั้งแต่ยังไม่เปิดอะไรเลย)

1. เปิดแอป **LINE PC** ให้ล็อกอิน แล้ว **ปักหมุดกลุ่มเป้าหมายไว้บนสุด** (แท็บ "ทั้งหมด")
2. เริ่มเซิร์ฟเวอร์ — เลือกวิธีใดวิธีหนึ่ง:
   - **ดับเบิลคลิกไฟล์ `run.bat`** (ง่ายสุด) — หรือ
   - เปิด PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์:
     ```bash
     python app.py
     ```
3. **เบราว์เซอร์จะเปิด http://localhost:5000 ให้อัตโนมัติ** (ถ้าไม่เปิด พิมพ์ URL นี้เอง)
4. ในหน้าเว็บ: ตรวจ **กลุ่มเป้าหมาย / ตารางข้อความ / รูป** → กด **💾 บันทึก** → กด **▶ เริ่ม**
5. **ปิดระบบ:** กด **■ หยุด** ในหน้าเว็บ (หยุดส่ง) และ/หรือปิดหน้าต่าง PowerShell / กด `Ctrl+C` (ปิดเซิร์ฟเวอร์)

> ครั้งแรกครั้งเดียว: ติดตั้งไลบรารีก่อนด้วย `pip install -r requirements.txt`

## 🖥️ หน้าเว็บ UI (รายละเอียด)

เปิด **http://127.0.0.1:5000** จะได้หน้าจอสำหรับ:
- ตั้งค่า **timezone / กลุ่มเป้าหมาย / พิกัด / delay / ตารางข้อความ** ผ่านฟอร์ม แล้วกด **บันทึก**
- ใส่ **รูป** ได้ (ช่อง "รูป (path)") — **หลายรูปก็ได้** พิมพ์บรรทัดละ 1 รูป หรือกดปุ่ม **📁 เลือกรูป** (เปิด File dialog)
- **หลายกลุ่ม:** ตาราง "กลุ่มเป้าหมาย" ใส่ชื่อ+พิกัดแถวได้หลายกลุ่ม ; แต่ละข้อความเลือกส่งกลุ่มไหน (ช่อง "กลุ่ม", เว้นว่าง=ทุกกลุ่ม)
- ปุ่ม **เริ่ม / หยุด** ตัวตั้งเวลา
- ปุ่ม **ส่งทดสอบทันที** (ส่งข้อความ/รูป/เลือกกลุ่มได้)
- ดูสถานะ: กำลังทำงาน, รอบส่งถัดไป, ส่งสำเร็จวันนี้, ผลล่าสุด
- ดู **Log สด** + ประวัติการส่ง

> ⚠️ ให้รัน **`app.py`** หรือ **`scheduler.py`** อย่างใดอย่างหนึ่ง — อย่ารันพร้อมกัน (จะส่งซ้ำ)
> การ calibrate พิกัดยังต้องใช้ `python calibrate.py` (ดูขั้นตอนด้านล่าง) แล้วค่าจะโชว์ในหน้า UI ให้แก้ได้

## ตั้งค่า (ทำครั้งเดียว)

> **หลักการทำงาน (พิสูจน์แล้วกับ LINE PC จริง):**
> 1. จัดหน้าต่างหลักไปตำแหน่งคงที่ → **double-click** แถวกลุ่มที่ปักหมุดบนสุด
> 2. LINE จะ **เด้งห้องแชตเป็นหน้าต่างแยก (ChatWindow) ที่มีชื่อกลุ่มเป็น title** → ระบบตรวจชื่อว่าตรงกับ `target_name` ก่อนส่ง (กันส่งผิดห้อง)
> 3. **พิมพ์ข้อความ (type) ไม่ใช่ paste** เพราะ LINE ไม่รับ Ctrl+V แล้วกด Enter ส่ง

### 1) เตรียม LINE
1. เปิด LINE PC ให้ล็อกอิน
2. ไปแท็บ **"ทั้งหมด"** แล้ว **ปักหมุด (Pin) กลุ่มเป้าหมายไว้บนสุด**
   (คลิกขวาที่กลุ่ม → ปักหมุด) — สำคัญมาก เพื่อให้ตำแหน่งแถวคงที่

### 2) สร้างไฟล์ config
คัดลอก `config.example.yaml` เป็น `config.yaml`:

```bash
copy config.example.yaml config.yaml
```

เปิด `config.yaml` แก้:
- `line.exe_path` — พาธ LINE.exe (เผื่อสคริปต์ต้องเปิด LINE เอง)
- `line.target_name` — **ชื่อกลุ่มเป้าหมาย** (ใส่เพื่อยืนยันว่าเปิดถูกห้องก่อนส่ง แนะนำให้ใส่)
- `messages` — เวลา/วัน/ข้อความที่จะส่ง

### 3) Calibrate พิกัดคลิก
รัน:

```bash
python calibrate.py
```

สคริปต์จะจัดหน้าต่าง LINE ให้ก่อน จากนั้น:
1. เอาเมาส์ไปวางบน **กลุ่มที่ปักหมุด (แถวบนสุด)** → จดค่า `relative=[x, y]`
   (ค่าเริ่มต้น `[240, 140]` มักใช้ได้เลยที่ขนาดหน้าต่าง 480×900)
2. กด `Ctrl+C` ออก
3. นำค่าไปใส่ `config.yaml → coords.chat_row`
   ```yaml
   coords:
     chat_row: [x, y]   # แถวกลุ่มบนสุด (ระบบจะ double-click แถวนี้)
   ```
   > `message_box` ไม่ต้อง calibrate แล้ว — ระบบพิมพ์ในหน้าต่างห้องแชตที่เด้งออกมา
   > (ถ้าคลิกช่องพิมพ์ไม่ตรง ปรับ `line.chat_input: [ระยะจากซ้าย, ระยะจากล่าง]`)

### 4) ทดสอบส่ง 1 ครั้ง

```bash
python send_once.py "ทดสอบส่งข้อความ ✅"
```

ถ้าข้อความเข้ากลุ่มถูกต้อง = ตั้งค่าเสร็จ 🎉
ถ้าคลิกพลาด → ปรับ `coords` หรือเพิ่มค่า `delays` ใน config แล้วลองใหม่

## ใช้งานจริง (ตั้งเวลาอัตโนมัติ)

รันค้างไว้:

```bash
python scheduler.py
```

- อ่านตาราง `messages` จาก `config.yaml` แล้วส่งตามเวลา
- log บันทึกที่ `line_sender.log`
- ปิดด้วย `Ctrl+C`

### รูปแบบ messages
```yaml
messages:
  - time: "09:00"      # HH:MM (24 ชม.)
    days: "mon-fri"    # mon-fri | mon,wed,fri | * (ทุกวัน)
    text: "สวัสดีตอนเช้าครับ ☀️"

  - time: "18:00"
    days: "*"
    text: |            # หลายบรรทัดได้
      สรุปประจำวัน
      - รายการ 1

  - time: "12:00"      # ส่งหลายรูป + ข้อความ + เลือกลำดับ
    days: "*"
    order: "text_first"  # image_first (ค่าเริ่มต้น) | text_first
    text: "รูปประจำวัน"
    image:               # ใส่ได้ 1 หรือหลายรูป (ส่งพร้อมกันครั้งเดียวเป็นอัลบั้ม)
      - "C:\\pics\\a.png"
      - "C:\\pics\\b.png"
```

> 🖼️ **ส่งรูป:** แต่ละรายการใส่ `image` เป็นพาธเดียว หรือ list หลายพาธก็ได้ — **หลายรูปจะถูกเลือกพร้อมกันในครั้งเดียวและส่งเป็นอัลบั้ม** (ไม่แยกทีละข้อความ)
> ในหน้า UI ช่อง "รูป (path)" และช่องส่งทดสอบ พิมพ์ **บรรทัดละ 1 รูป** เพื่อส่งหลายรูป
> 🔀 **ลำดับส่ง (`order`):** เลือกได้ว่าจะ **ส่งรูปก่อนข้อความ** (`image_first`) หรือ **ข้อความก่อนรูป** (`text_first`) — เลือกในหน้า UI คอลัมน์ "ลำดับส่ง"

## ให้รันอัตโนมัติตอนเปิดเครื่อง (Task Scheduler)

มีสคริปต์ติดตั้งให้แล้ว — เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```bash
powershell -ExecutionPolicy Bypass -File .\install_task.ps1
```

สคริปต์จะ:
- สร้าง task ชื่อ **"LINE PC Scheduler"** ให้รัน `scheduler.py` อัตโนมัติทุกครั้งที่ล็อกอิน (หน่วง 1 นาที)
- ใช้ `pythonw.exe` (ไม่มีหน้าต่าง console เด้ง) และรันแบบ Interactive (มีหน้าจอให้ automation ทำงาน)
- ไม่หยุดเมื่อใช้แบต / รีสตาร์ทเองถ้าพัง 3 ครั้ง

คำสั่งที่เกี่ยวข้อง:
```bash
powershell -ExecutionPolicy Bypass -File .\uninstall_task.ps1
```

- ทดสอบรันทันที: `Start-ScheduledTask -TaskName "LINE PC Scheduler"`
- ดูสถานะ: `Get-ScheduledTask -TaskName "LINE PC Scheduler"`

> ถ้าเจอ **Access Denied** ให้เปิด PowerShell แบบ **Run as administrator** แล้วรันใหม่
> ⚠️ ต้อง **calibrate พิกัด + ปักหมุดกลุ่ม + ทดสอบ send_once.py** ให้ผ่านก่อน ค่อยติดตั้ง task

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|------|--------|
| หาหน้าต่าง LINE ไม่เจอ | เปิด LINE ค้างไว้ / ตั้ง `exe_path` ให้ถูก |
| "ไม่พบ ChatWindow" หลัง double-click | ปักหมุดกลุ่มบนสุดในแท็บ "ทั้งหมด" + calibrate `chat_row` ใหม่ + เพิ่ม `delays.after_open_chat` |
| "ห้องที่เปิดไม่ตรงเป้าหมาย" | แก้ `target_name` ให้ตรงชื่อกลุ่ม หรือปักหมุดกลุ่มให้ถูก |
| ข้อความไม่ลงช่องพิมพ์ | ปรับ `chat_input: [ซ้าย, ล่าง]` / เพิ่ม `delays.after_click_box` |
| ข้อความไทยเพี้ยน | ระบบพิมพ์แบบ unicode อยู่แล้ว (ไม่ใช้ paste) — ปกติไม่เพี้ยน |
| ทำงานพลาดเมื่อเครื่องช้า | เพิ่มค่าใน `delays` ทุกตัว 0.5–1.0 วิ |
| เมาส์วิ่งไปมุมจอแล้วโปรแกรมหยุด | เป็น fail-safe ของ pyautogui (กันพัง) — อย่าขยับเมาส์ตอนส่ง |
